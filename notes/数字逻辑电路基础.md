# 数字逻辑电路基础

> 处理器芯片本质上是数字电路。数字电路处理的是 0 和 1 两种离散信号（逻辑 0 和逻辑 1）。

本章是「一生一芯」F 阶段第 3 章，涵盖数字电路的三个核心问题：

## 如何表示 — 0 和 1 的物理实现

- [[nMos|nMOS 晶体管]] — N 型 MOS，高电平导通
- [[pMos|pMOS 晶体管]] — P 型 MOS，低电平导通
- 晶体管作为电压控制的开关，栅极控制源漏通断
