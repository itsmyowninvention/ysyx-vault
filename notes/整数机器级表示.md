# 整数的机器级表示

计算机中整数的三种编码方式。

## 原码（sign-and-magnitude）

- 最高位为**符号位**：0 表示正，1 表示负
- 其余位表示数值的绝对值
- 例（4 位）：$+5 = 0101_2$，$-5 = 1101_2$

**缺点**：
- 有 +0（0000）和 -0（1000）两个零
- 加减法需要分别处理符号和数值，电路复杂

## 反码（one's complement）

- 正数的反码 = 原码
- 负数的反码 = 原码**按位取反**（符号位也取反）
- 例（4 位）：$+5 = 0101_2$，$-5 = 1010_2$

**缺点**：
- 仍有 +0（0000）和 -0（1111）
- 加法需要循环进位（end-around carry）

## 补码（two's complement）

现代计算机普遍使用的编码方式。

### 定义

- 正数的补码 = 原码
- 负数的补码 = **反码 + 1**
- 例（4 位）：$+5 = 0101_2$，$-5 = 1011_2$

### 性质

- **唯一零**：0000（没有 -0）
- n 位补码的表示范围：$-2^{n-1}$ 到 $2^{n-1}-1$
- 最高位仍是符号位，但也是数值的一部分（权重为 $-2^{n-1}$）
- **加减法统一**：减法 = 加补码（$A - B = A + (-B)_{补}$），无需额外电路

### 补码运算示例（4 位）

- $5 + (-3)$：$0101 + 1101 = (1)0010 = 2$ ✓
- $(-2) + (-3)$：$1110 + 1101 = (1)1011 = -5$ ✓

> 进位超出位宽的部分直接丢弃（模运算）。

## 溢出检测

当运算结果超出表示范围时发生溢出。

### 判断方法

1. **符号位判断**：
   - 两个正数相加得负数 → 上溢
   - 两个负数相加得正数 → 下溢
   
2. **进位判断**：
   - 最高位进位 $C_n$ ≠ 次高位进位 $C_{n-1}$ → 溢出
   - $Overflow = C_n \oplus C_{n-1}$

3. **双符号位**：
   - 用两位表示符号（00=正，11=负）
   - 结果符号位为 01 或 10 → 溢出

| 操作 | A | B | 结果 | 溢出？ |
|------|:---:|:---:|:---:|:---:|
| 5+3 | 0101 | 0011 | 1000(-8) | ✓ 上溢 |
| (-5)+(-3) | 1011 | 1101 | (1)1000(8) | ✓ 下溢 |
| 5+(-3) | 0101 | 1101 | (1)0010(2) | ✗ |
