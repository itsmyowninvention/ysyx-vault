# 进位计数法

## 二进制计数法

- 基数为 2，每位数码为 0 或 1
- 位权：$2^n, 2^{n-1}, \ldots, 2^1, 2^0$
- 例：$1011_2 = 1 \times 2^3 + 0 \times 2^2 + 1 \times 2^1 + 1 \times 2^0 = 11_{10}$

### n 位二进制数的表示范围

- 无符号：$0$ 到 $2^n - 1$
- 例：8 位 → 0 到 255

### 十进制转二进制

- **整数部分**：除 2 取余，逆序排列
- **小数部分**：乘 2 取整，顺序排列

## 十六进制计数法

- 基数为 16
- 数码：0-9, A(10), B(11), C(12), D(13), E(14), F(15)
- 1 位十六进制 = 4 位二进制

### 二进制与十六进制互转

| 二进制 | 十六进制 |
|--------|:---:|
| 0000 | 0 |
| 0001 | 1 |
| 0010 | 2 |
| 0011 | 3 |
| 0100 | 4 |
| 0101 | 5 |
| 0110 | 6 |
| 0111 | 7 |
| 1000 | 8 |
| 1001 | 9 |
| 1010 | A |
| 1011 | B |
| 1100 | C |
| 1101 | D |
| 1110 | E |
| 1111 | F |

- 二进制 → 十六进制：从右往左每 4 位一组转换
- 十六进制 → 二进制：每位展开为 4 位
- 例：$1011\,1100_2 = BC_{16}$

### 常用十六进制表示

- 前缀 `0x`：`0xBC` = $BC_{16}$
- 前缀 `h`：Verilog 中 `8'hFF` = 8 位宽、值 FF

## 任意进制转十进制

按位权展开求和即可。
